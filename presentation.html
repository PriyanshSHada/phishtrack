PhishTrack

Mobile Threat Intelligence Platform

Empowering SOC Analysts on the go

The Problem

Why we need a better tool

  • Phishing attacks are rising rapidly, targeting employees everywhere.
  • Incident Response teams are tied to their desktop environments.
  • Manual evidence gathering across OSINT tools is incredibly slow.
  • Lack of proper chain of custody tracking for digital evidence.

The Solution

PhishTrack

  • A Full-Stack Mobile Platform: Brings power to the palm of your hand.
  • One-tap automated analysis executing 5+ threat checks instantly.
  • Cryptographically secure Chain of Custody for evidence preservation.
  • Seamless SOC-on-the-go experience for rapid triage.

System Architecture

End-to-End Flow

Frontend: Android App (Kotlin / Jetpack Compose)

⬇️ REST API via Retrofit ⬇️

Backend: Node.js & Express API Server

⬇️ Prisma ORM ⬇️

Database: PostgreSQL hosted on Supabase

Cloud Infra: Deployed seamlessly via Render

Core Feature: Threat Map

  • Interactive map visualizing the geographic origin of phishing attacks.
  • Live statistics on emerging campaigns (e.g., WhatsApp vs Email).
  • Real-time dashboard summarizing the team's ongoing case load.
  • Trend graphs identifying spikes in phishing activities.

Automated Analysis Engine

PhishTrack aggregates intelligence from multiple sources instantly:

  • VirusTotal: Sandboxed URL and IP scanning.
  • WHOIS: Domain registration age and registrar details.
  • SSL Validation: Certificate verification and trust chaining.
  • Homograph Checks: Detecting lookalike "typosquatted" domains.
  • MITRE ATT&CK: Mapping observed behaviors to known techniques.

Forensic Reporting

  • Automatically compile comprehensive PDF reports.
  • Includes network indicators, analysis verdicts, and AI summaries.
  • Tamper-Proof: Files are stored in Supabase with database-level buffer backups.
  • Integrity: Every report is tied to a cryptographic signature.

Frontend: Android Native

Kotlin Jetpack Compose Retrofit Coroutines
  • MVVM Architecture: Clean separation of UI and logic.
  • Offline Caching: Room database integration ensures fast loading.
  • Material Design 3: Dark-mode native interface with micro-animations.
  • OTP Authentication: Secure email-based login flows.

Backend: Node.js Power

Node.js Express Prisma ORM PDFKit
  • Secure JWT authentication with express-rate-limit.
  • Asynchronous threat intelligence orchestration.
  • Robust error handling with Winston logging.
  • Dynamic PDF generation using PDFKit streams.

Conclusion & Future Scope

  • It enables SOC analysts to triage critical incidents from anywhere.
  • Future Scope:
